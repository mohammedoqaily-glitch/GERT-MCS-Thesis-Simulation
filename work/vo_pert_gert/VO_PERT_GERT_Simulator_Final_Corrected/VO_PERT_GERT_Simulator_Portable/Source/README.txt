VO PERT-GERT Monte Carlo Simulator

This package contains a native Windows-friendly Tk desktop application, Monte Carlo engines, Excel workbook generation, raw CSV export, tests, and a Windows PyInstaller rebuild script.

The original request referenced additional attached Word, Markdown, Python, case-data, and Excel files, but only the pasted build brief was available in the attachment folder. The included default case is a demonstration network and must be replaced with the authoritative supplied case data for final research use.

Run source:
python -m vo_pert_gert

Run tests:
python run_tests.py

Build Windows executable:
powershell -ExecutionPolicy Bypass -File build_windows.ps1
